
# Intelligent Courier Planning System

## 1. Project Overview
The Intelligent Courier Planning System is a Python-based
application that optimizes parcel selection and delivery routes.

It combines Sorting, Dynamic Programming, Graph Algorithms
and Approximation Techniques.

## 2. Objectives
- Prioritize parcels based on priority and deadlines.
- Select optimal parcels using 0/1 Knapsack.
- Calculate shortest paths using Dijkstra.
- Generate delivery routes using Nearest Neighbor TSP.
- Analyze algorithm performance.

## 3. Technologies Used
- Python
- VS Code
- Matplotlib
- JSON
- Graph Algorithms

## 4. Algorithms Used

| Algorithm | Purpose |
|---|---|
| Merge Sort | Parcel prioritization |
| 0/1 Knapsack | Package selection |
| Dijkstra | Shortest path |
| Nearest Neighbor | Route optimization |

## 6. Installation

Install dependencies:

pip install -r requirements.txt

## 7. Execution

Run the main application:

python main.py

Run performance testing:

python performance.py

## 8. Output
The system displays:
- Sorted parcels
- Selected packages
- Total weight and value
- Delivery route
- Total distance
- Runtime comparison chart

## 9. Conclusion
The project demonstrates how different algorithms
can be integrated to solve a real-world courier
planning problem.
